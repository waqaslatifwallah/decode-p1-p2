# DecodeLabs Internship Project 01

A responsive landing page built during my internship at DecodeLabs, focusing on modern frontend development practices, responsive layouts, and semantic HTML structure.

---

## 📌 Project Overview

This project was developed as part of my internship journey at **DecodeLabs** to strengthen my understanding of modern web development fundamentals.

The goal was to create a clean, responsive landing page while practicing:

* Semantic HTML5 structure
* CSS Grid Layout
* Responsive Web Design
* Mobile-First Development Principles
* Clean and Maintainable Code Organization
